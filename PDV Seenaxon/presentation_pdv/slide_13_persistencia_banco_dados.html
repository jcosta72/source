Persistência em Banco de Dados

SQLite integrado para salvar produtos, operadores, vendas e itens com backup automático

Tabelas do Banco

  • Produtos (ID, Nome, Descrição, Preço)
  • Operadores (ID, Nome, Matrícula, Senha)
  • Vendas (ID, OperadorID, Subtotal, Desconto)
  • ItensVenda (ID, VendaID, ProdutoID, Quantidade)
  • Caixas (ID, DataAbertura, DataFechamento, Saldo)

Operações CRUD

  • Criar (INSERT) - Adicionar novos registros
  • Ler (SELECT) - Consultar dados
  • Atualizar (UPDATE) - Modificar registros
  • Deletar (DELETE) - Remover registros
  • Transações - Integridade de dados

Backup e Restauração

  • Backup automático diário
  • Restauração de backup
  • Versionamento de dados
  • Recuperação de falhas
  • Sincronização de dados
