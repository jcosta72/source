Tecnologias Utilizadas

Stack profissional com Delphi 12 Sydney, FireMonkey FMX, SQLite e padrões de design

Linguagem e Framework

  • Delphi 12 Sydney
  • FireMonkey (FMX)
  • Multiplataforma (Windows, macOS, Linux)
  • Compilação nativa
  • Performance otimizada

Banco de Dados

  • SQLite 3
  • Integração com FireDAC
  • Transações ACID
  • Backup automático
  • Sem servidor externo

Padrões de Design

  • Programação Orientada a Objetos (POO)
  • Model-View-Controller (MVC)
  • Repository Pattern
  • Dependency Injection
  • Single Responsibility Principle

Formatos de Arquivo

  • XML (Recuperação de vendas)
  • CSV (Exportação de dados)
  • TXT (Relatórios simples)
